================================================================================
                       OPTION A: AUTOMATED SETUP
================================================================================

The easiest way to deploy is using our automated scripts:

WINDOWS:
   1. Open PowerShell in project directory
   2. Run: .\deploy.ps1
   3. Follow the interactive prompts
   4. Choose option 1 (Local) or 2 (Docker)

LINUX/MAC:
   1. Open Terminal in project directory
   2. Run: chmod +x deploy.sh
   3. Run: ./deploy.sh
   4. Follow the interactive prompts
   5. Choose option 1 (Local) or 2 (Docker)

That's it! The script will:
   ✓ Check prerequisites
   ✓ Create virtual environment
   ✓ Install dependencies
   ✓ Configure environment
   ✓ Start the application

================================================================================
                       OPTION B: MANUAL LOCAL SETUP
================================================================================

STEP 1: Setup Environment
   - Copy .env.example to .env
   - Edit .env and add your API keys:
     GOOGLE_API_KEY=your_actual_key_here
     TAVILY_API_KEY=your_actual_key_here

STEP 2: Install Dependencies

   WINDOWS (PowerShell):
      python -m venv venv
      .\venv\Scripts\Activate.ps1
      pip install -r requirements.txt

   LINUX/MAC (Terminal):
      python3 -m venv venv
      source venv/bin/activate
      pip install -r requirements.txt

STEP 3: Start Application
   uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

STEP 4: Open Browser
   - Landing Page: http://localhost:8000
   - Chat App: http://localhost:8000/app
   - API Docs: http://localhost:8000/docs

================================================================================
                       OPTION C: DOCKER DEPLOYMENT
================================================================================

Prerequisites: Docker Desktop installed and running

STEP 1: Configure Environment
   - Copy .env.example to .env
   - Edit .env with your API keys

STEP 2: Start Services
   docker-compose up -d

STEP 3: Access Application
   http://localhost:8000

STEP 4: View Logs (Optional)
   docker-compose logs -f

STEP 5: Stop Services
   docker-compose down

================================================================================
                    OPTION D: CLOUD DEPLOYMENT (EASY)
================================================================================

RAILWAY (Easiest - 10 minutes):
   1. Sign up at https://railway.app
   2. Click "New Project"
   3. Select "Deploy from GitHub repo"
   4. Connect your repository
   5. Add environment variables:
      - GOOGLE_API_KEY
      - TAVILY_API_KEY
      - LLM_PROVIDER=google
   6. Click "Deploy"
   7. Railway provides a URL automatically

RENDER (Free Tier - 10 minutes):
   1. Sign up at https://render.com
   2. Click "New +" → "Web Service"
   3. Connect GitHub repository
   4. Select "Docker" as environment
   5. Add environment variables:
      - GOOGLE_API_KEY
      - TAVILY_API_KEY
      - LLM_PROVIDER=google
   6. Click "Create Web Service"
   7. Wait for deployment (5-10 minutes)

================================================================================
                           COMMON ISSUES
================================================================================

ISSUE: Port 8000 already in use
   WINDOWS: netstat -ano | findstr :8000
            taskkill /PID <PID> /F
   LINUX:   lsof -ti:8000 | xargs kill -9

ISSUE: API Key Invalid
   - Check .env file exists in project root
   - Verify no extra spaces in API key
   - Test API key at provider dashboard

ISSUE: Module not found
   pip install --upgrade -r requirements.txt

ISSUE: Docker won't start
   - Make sure Docker Desktop is running
   - Restart Docker Desktop
   - Check Docker daemon status

ISSUE: Redis connection failed
   - This is OK! App uses in-memory cache as fallback
   - To add Redis: docker run -d -p 6379:6379 redis:alpine

================================================================================
                         PERFORMANCE TIPS
================================================================================

For faster responses:

1. Enable Redis (optional but recommended):
   REDIS_ENABLED=true
   REDIS_URL=redis://localhost:6379/0

2. Use Groq for faster LLM inference:
   LLM_PROVIDER=groq
   LLM_MODEL=llama-3.3-70b-versatile

3. Optimize caching:
   CACHE_STABLE_TTL=86400    # 24 hours for stable data
   CACHE_VOLATILE_TTL=300    # 5 minutes for real-time data
